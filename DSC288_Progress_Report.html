1. Background & Problem Statement

1.1 Problem Statement

The rise of AI-driven trading has created a critical trust gap: while algorithmic systems become increasingly sophisticated at predicting market movements, they remain opaque "black boxes" that provide recommendations without explanation. Retail investors receive buy, hold, or sell signals but have no visibility into the reasoning behind these decisions.

❌ The Trust Problem

Users cannot verify if recommendations are based on sound analysis or flawed assumptions, eroding confidence in AI-powered financial tools.

❌ The Learning Problem

Without explanations, investors cannot develop financial literacy or understand market dynamics—they remain dependent on the black box.

❌ The Accountability Problem

When recommendations fail, there is no audit trail to understand what went wrong or how to improve future decisions.

1.2 Our Proposal: Explainable Graph RAG Trading System

We propose a Multi-Agent Graph RAG System that prioritizes explainability over pure prediction accuracy. Every trading recommendation comes with:

📝 Natural Language Explanations

"Based on positive earnings news and upward momentum, we recommend buying AAPL" — not just "BUY: 0.73"

🔗 Cited Sources

Every claim is grounded in specific news articles, financial data, or technical indicators with traceable provenance

⚖️ Balanced Perspectives

Optimistic and Cautious agents debate before synthesis, ensuring users see both bullish arguments and risk factors

🕸️ Knowledge Graph Reasoning

Neo4j stores entity relationships enabling multi-hop queries like "Find stocks affected by the same executive"

1.4 Our Three Technology Pillars

🕸️ Neo4j Knowledge Graph

Stores entities (stocks, articles, people, events, sentiment) and their explicit relationships. Unlike vector databases, this enables complex multi-hop queries: "Find all stocks mentioned positively by analysts who were bearish on AAPL last quarter."

🤖 GPT-5.2 + OpenAI Agents SDK

Uses the official OpenAI Agents SDK for production-grade multi-agent orchestration. Specialist agents (fundamental, technical, sentiment) hand off to each other with full context preservation—unlike custom LangChain implementations.

🔗 Sentiment-to-Signal Modeling

Creates auditable graph edges from news articles → sentiment scores → trading signals. Every recommendation can be traced back to the specific articles and data points that influenced it.

1.5 Target Users

Intermediate and beginner retail investors who value understanding financial recommendations over opaque numerical predictions. Our system helps users learn why markets move, not just what to trade—building genuine financial literacy through explainable AI.

5.3 Sentiment Model Architecture

Training Data

Financial Phrasebank provides 2,264 human-annotated sentences with sentiment labels (positive, neutral, negative) specifically for financial text.

Model Choice

Fine-tuned FinBERT or GPT-5.2 with structured outputs for domain-specific sentiment classification with confidence scores.

Output Format

Each article produces: sentiment score (-1 to +1), confidence (0 to 1), label (bullish/neutral/bearish), and key phrases for citation.

6. Proposed System Architecture

6.1 System Overview

Our multi-agent Graph RAG system combines three core technologies to deliver explainable financial recommendations:

🕸️ Neo4j Knowledge Graph

Stores entities (stocks, articles, people, events) and their relationships, enabling complex multi-hop reasoning across financial data.

🤖 GPT-5.2 LLM

Performs entity extraction from news, sentiment classification, and generates natural language explanations for recommendations.

🔧 OpenAI Agents SDK

Orchestrates multiple specialist agents (fundamental, technical, sentiment analysts) that collaborate through structured handoffs.

Relationships

7.2 Example: How Graph RAG Answers a Trading Question

When a user asks "Should I buy AAPL?", our system traverses the knowledge graph to gather evidence. Here's a simplified example of how Cypher queries retrieve relevant information:

// Step 1: Find recent news articles about AAPL and their sentiment
MATCH (stock:Stock {ticker: 'AAPL'})
      -[:MENTIONED_IN]->(article:Article)
      -[:HAS_SENTIMENT]->(sentiment:Sentiment)
WHERE article.date > '2026-01-25'
RETURN article.title, article.date, sentiment.score, sentiment.label
ORDER BY article.date DESC
// Example Result:
Title Date Score Label
"Apple Q1 earnings beat expectations" 2026-01-28 +0.85 POSITIVE
"iPhone sales surge in China market" 2026-01-27 +0.72 POSITIVE
"Supply chain concerns ease for Apple" 2026-01-26 +0.45 NEUTRAL
// The agent then generates an explanation with citations:
Recommendation: BUY AAPL

Based on recent news analysis, AAPL shows positive sentiment (avg score: +0.67).
Key factors:
• Q1 earnings exceeded expectations [Article #1, 2026-01-28]
• Strong iPhone demand in China [Article #2, 2026-01-27]
• Supply chain stabilizing [Article #3, 2026-01-26]

This example demonstrates how the Graph RAG system provides explainable recommendations by traversing the knowledge graph and citing specific sources for each claim.

Risk Probability Impact Mitigation Strategy
Low news coverage (1.46%) High Medium Supplement with Yahoo Finance API; design system for technical-only analysis when news unavailable
OpenAI API rate limits Medium High Implement caching layer; batch API calls; optimize prompt efficiency
Neo4j query performance Medium Medium Optimize Cypher queries; create indexes on frequently queried properties
Entity extraction accuracy Medium High Use GPT-5.2 structured outputs; implement validation layer; human review sample
Model hallucination Medium High Ground all claims in RAG sources; implement citation verification; constrain to graph content
